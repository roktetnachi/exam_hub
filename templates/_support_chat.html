{% comment %} Help chat: a floating "Help" button that answers common questions from the starter guide and, when that isn't enough, sends a message to the Andam support team (POST /support/message/ → emailed to SUPPORT_EMAIL, also kept in Django admin → Support requests). Included on the landing, sign-in, guide, Exams and teacher pages. Hidden while a pupil is in an exam (body.exam-focus). Any element with [data-open-support] opens it; give the attribute a topic (e.g. data-open-support="school_enquiry") to go straight to "Message support" with that topic. Everything here is namespaced .sc- / scX so it can't clash with the page it sits on. {% endcomment %} {% load static %}
